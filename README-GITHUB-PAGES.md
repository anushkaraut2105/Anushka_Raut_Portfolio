# Anushka Raut Portfolio

## GitHub Pages deployment
1. Extract this ZIP.
2. Open the extracted `Anushka_Raut_Portfolio-main` folder.
3. Upload the **contents of this folder** to the root of your GitHub repository (the `index.html`, `style.css`, `script.js`, `public/`, and `imports/` items should be directly at repository root).
4. Commit and push the changes.
5. In GitHub, open **Settings → Pages** and select **Deploy from a branch**, branch `main`, folder `/ (root)`.

The static HTML page uses paths relative to the repository so it works when hosted at a GitHub Pages project URL such as `https://username.github.io/repository/`.
